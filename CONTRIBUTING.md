# Contributing

Thanks for helping improve the Lantide Data plugin.

## Before opening a pull request

1. Keep the plugin useful without relying on promotional claims.
2. Treat the running Lantide application as the source of truth for tools, permissions, and workspace state.
3. Never add credentials, private datasets, customer configuration, or private-repository details.
4. Keep setup instructions least-privilege and provider-neutral where practical.
5. Run `python3 scripts/validate.py` from the repository root.

Use focused commits and explain the user-visible behavior changed by the pull request. For a new skill, include clear trigger conditions, non-goals, safe fallbacks, and an `agents/openai.yaml` interface file.

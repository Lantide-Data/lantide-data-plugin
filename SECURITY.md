# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `support@lantidedata.com`. Do not open a public issue for a vulnerability that could expose credentials, local data, or user systems.

Include the affected plugin version, operating system and client versions, a minimal reproduction, impact, and redacted logs. Never send pairing credentials or private datasets.

## Scope

This repository contains public onboarding and troubleshooting instructions. Security issues in Lantide Data Desktop, Agent Integration, or its local MCP endpoint should also be reported through the private address above.
